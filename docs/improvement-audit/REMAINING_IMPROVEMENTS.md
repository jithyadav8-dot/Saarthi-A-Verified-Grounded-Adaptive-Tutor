# Remaining improvements and blockers

The immediate product gap is a course-linked assessment bank. A learner can upload a deck and retrieve a recovered formula, but the default quiz still draws from bundled items. In the cold-start fixture only 11 questions were eligible out of 25 requested. Expanding this bank with traceable, reviewed items would support more practice and make equal-exposure policy experiments possible.

| Open work | Dependency or evidence gap | Smallest next deliverable and acceptance test |
|---|---|---|
| Course bank and verified question publication | Source versions, course identity and reviewable item keys. Existing generator, blind solver, math check and dedup are separate modules. | Pilot one rights-cleared course. Persist candidate, quote/span, independent solve record, numeric computation if applicable, difficulty and reviewer disposition. On replacement, retire items whose evidence disappeared. Verify upload → approved item → grading → inspectable feedback. |
| Semantic support and partial evidence | The deterministic screen accepts some relational errors and may reject sound derivations. A model judge can share generator errors. | Have two independent reviewers annotate contradiction, insufficient evidence, inference and exact support on unseen courses. Freeze thresholds before testing. Publish false acceptance and false refusal rates alongside coverage. |
| Graph quality | Acyclicity, order and text mention are weak proxies for a true prerequisite. | Sample accepted and rejected edges for expert review. Track precision and false gating by concept. Only validated edges should block practice. |
| Learner calibration and equal-exposure comparison | Item difficulty, guess/slip, time decay and conversation signals lack real calibration. Current simulator omits difficulty and forgetting. | Run matched-exposure sensitivity experiments with exhaustion, easy/hard profiles and held-out seeds. Fit item parameters only with sufficient learner evidence. Evaluate calibration on future responses. A consented study with delayed testing is needed for learning effectiveness. |
| Misconception tracking and lessons | Bundled questions often lack reviewed distractor explanations or accessible source units. | Start with one subject, repeated error signatures, an explicit uncertain state, cited remediation text and a fresh transfer question. Compare usefulness with ordinary feedback. Evaluate audio/video only after validating the text workflow and securing voice/media rights. |
| PDFs, images, videos and fine locators | Real vision/ASR assets and diverse labeled materials were unavailable within this offline audit. Office Math support covers common native forms only. | Add licensed scanned/vector equation, diagram, table and whiteboard fixtures. Compare native, selective and full vision on identical inputs. Measure formula/label correctness, time alignment, call budget and memory. Preserve bounding boxes where the parser actually provides them. |
| Data isolation, ingestion and recovery | Single shared corpus, caller IDs, process-local locks, filename-derived identities, and multiple persistent files. Upload byte limits do not bound decoded resource use. | Design course/owner schema and migration, generation-based index publication, bounded decoding and resumable jobs. Verify permission boundaries and crash recovery before external deployment. |
| Replay, dependencies and frontend debt | Caches need retention/version policy. Current environment uses preinstalled packages. ESLint still reports 21 errors and 34 warnings. | Lock an offline-capable installation profile, add CI from an empty environment, fix lint violations by component, and automate browser submit/reload/source inspection. |
| Comparative neural retrieval and end-to-end speed | No shared licensed course evaluation, pinned local neural weights or approved hosted inference run. | Use identical input units, queries, gold labels, hardware and budgets. Compare BM25, dense, hybrid, reranker and optional query rewrite separately. Report p50/p95, process RSS, tokens, failure denominators and answer quality. |
| Pramana reproduction | Full pytest collection requires pypdfium2. Course rebuild and video rendering require additional dependencies, course media and models. | Pin optional dependencies in a separate environment, comply with course licenses, then run the full suite and a replayed course. Record missing assets and distinguish cached replay from fresh inference. |
